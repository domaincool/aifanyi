1. 系统架构

整体为 Next.js 全栈单体：App Router 服务端渲染（梗翻译 SEO 靠 SSR 吃长尾词），API Route 承载业务接口，Prisma 访问 PostgreSQL。所有翻译请求统一走「翻译路由器」——模型适配层 + 缓存 + 选路，外部模型 API 全部从这一层进出，保证换模型不改业务代码。

2. 模块与数据模型

核心表（Prisma schema 已落地）
  • users — 账号体系（MVP 匿名 + 可选登录）
  • blindtests — 盲测题：原文 + 多模型匿名译文（JSONB）
  • votes — 投票记录：谁投了哪个模型译文
  • meme_entries — 梗词条库：YYDS→God-tier，SEO 页数据源
  • translation_jobs — 翻译任务：原文哈希、模型、成本、耗时、质量自评
  • corpus_entries — 语料库：场景/语言对/质量标签（飞轮主库）
  • corrections — 纠错对：错误译文 + 人工修正
  • termbase_entries — 垂直术语库（电商/游戏/法律…）
  • glossaries — 用户词库（工作台品牌词锁定）
API 设计（v0.1）
  • POST /api/translate — 路由器入口：原文+场景+风格 → 多模型译文 + 成本计量
  • POST /api/blindtest — 创建盲测（调 3–4 模型各译一版）
  • POST /api/votes — 投票 + 偏好数据自动入库
  • GET /meme/[slug] — 梗词条 SSR 页面（SEO 长尾）
  • 后续：/api/workbench/* 工作台、/api/glossary 词库

3. 成本控制（预算 ¥1000/月）

DeepSeek 主路由成本极低，¥1000/月对 MVP 阶段非常充裕。关键不是省，而是不重复花钱：缓存 + 哈希去重 + 低质不重试。

项目测算月成本
DeepSeek 主路由（输入 ¥2/百万 token，输出 ¥8/百万 token）日均 20 万输入 + 5 万输出 token≈ ¥24
GLM-4 备选（便宜档/免费档）盲测多模型对比用≈ ¥10–30
DeepL免费层 50 万字符/月，超出按量≈ ¥0–60
服务器 / RDS / 域名FC 香港按量 + RDS PG 基础档≈ ¥100–200
预留（Claude mini 等升级档）工作台高价值场景≈ ¥300–500
合计≈ ¥500–800，留 20% 余量
省钱三板斧：① 梗翻译一次性生成入库，之后 100% 读缓存零成本；② 所有翻译请求先查原文 SHA-256 哈希，重复原文直接命中历史结果；③ 路由层记录每次调用的 token/成本，超预算自动降级到 GLM 免费档。

4. 开发计划（4 周出双入口 MVP）

WEEK 1 · 地基
仓库 + Schema + 翻译路由器 + 基础 UI
初始化 Next.js 项目；Prisma 全量表迁移；写通 DeepSeek/GLM/DeepL 三个 Provider 与路由/缓存/去重；首页放一个可用翻译框。里程碑：翻译路由器跑通，成本计量生效。
WEEK 2 · 双入口上线
梗翻译器 + 盲测擂台 v1
梗词条库先灌 200 条（YYDS/栓Q/绝绝子…），每词一条 SSR 页吃 SEO；盲测擂台：创建题 → 多模型匿名译文 → 投票 → 实时榜单。里程碑：aifanyi.com 可访问，双入口在线。
WEEK 3 · 数据管线 + 工作台 v0
投票/纠错入库管线；工作台手工辅助工具
投票与翻译结果自动写语料库；做「找翻译茬」纠错入口；工作台 v0 = 粘贴中文 → 选市场/风格 → 出多版 Listing 译文，服务 10 个种子卖家。里程碑：数据飞轮第一次转动。
WEEK 4 · 部署 + 增长
FC 香港部署 + SSL + SEO 基础 + 监控
打包上传 FC（node server.js 启动，9000 端口）；域名解析 + HTTPS；sitemap 提交百度/必应；接入错误监控与用量看板。里程碑：稳定运行，开始种子用户服务。
