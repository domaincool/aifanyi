架构核心

统一账户模型

  • User 统一账户（未来 Subscription/Credit owner）
  • AuthIdentity 多身份绑定：google / email / 未来 apple / wechat
  • 账户合并仅基于 verified email，绝不自动合并未验证字符串
  • Google 仅作 Authentication Provider，登录态由自有 Session 维持

会话与安全

  • JWT(HS256)+DB 双写，30 天过期，可撤销（revokedAt）
  • Cookie HttpOnly + Secure + SameSite=Lax，无 localStorage token
  • 最小 scope：openid email profile，无 refresh token
  • 所有资源 API 强制 ownership 检查
