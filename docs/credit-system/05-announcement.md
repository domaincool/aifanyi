## 爱翻译上线「使用额度」体系 🎉

亲爱的用户：

为了让翻译服务更稳定、更透明地持续运行，爱翻译已上线全新的**「使用额度」体系**。简单说：**放心用，翻译成功才计费，失败自动退回**。

### 你会看到的变化

**1. 登录即送 300 免费额度**
- 新老用户登录后自动到账 300 使用额度（30 天内有效）
- 额度用完后仍可继续使用，按实际用量计费，用量透明可查

**2. 用量透明，绝不乱扣**
- 每次翻译前都知道大概消耗多少
- **只有翻译成功才扣额度**；失败、取消、任务中断都会自动退回
- 缓存命中的重复翻译不扣额度

**3. 文件翻译需登录使用**
- PDF / 字幕 / 图片 / 网页 / Word·PPT 翻译现在需要登录后使用（登录即送 300 额度，足够日常使用）
- 这是为了防止服务被滥用、保证翻译质量与速度

**4. 随时查看使用情况**
- 右上角用户菜单 →「我的额度」，可查看剩余额度、本月用量与最近记录

### 常见问题

**Q：我之前没登录也能用 PDF 翻译，现在必须登录吗？**
A：是的。登录即可获得 300 免费额度，比之前的每日文件数限制更宽松、更透明。

**Q：额度用完了怎么办？**
A：额度用完后仍可继续使用，按实际用量计费。每次翻译前都会提示预计消耗，不会突然扣费。

**Q：翻译失败了会扣额度吗？**
A：不会。只有翻译成功的部分才计费，失败、取消、中断都会自动退回额度。

**Q：盲测擂台还免费吗？**
A：免费，盲测擂台永远免费。
