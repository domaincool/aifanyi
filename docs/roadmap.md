# aifanyi.com 开发路线图

> 版本 v0.1 · 2026-08-08 · 基于三角战略（工作台赚钱 / 双入口吸流 / 数据飞轮建壁垒）

## 已确认的约束

| 项目 | 结论 |
|---|---|
| 域名 | aifanyi.com 已在名下，**未备案**（公司注册中，注册完走备案） |
| 部署 | 阶段一：阿里云 FC **香港节点**（免备案）；阶段二：备案后迁国内节点 |
| 模型预算 | **¥100/月**，DeepSeek 主路由 + GLM 备选 + DeepL 保底 |
| 收款 | 支付宝先行（等营业执照），Stripe 后置（海外主体时） |
| 技术栈 | Next.js 15 + TS + Tailwind + PostgreSQL + Prisma |
| 团队 | 单人开发起步 |

## 里程碑

- **M1（第 2 周末）**：aifanyi.com 可访问，盲测擂台 + 梗翻译双入口在线
- **M2（第 4 周末）**：数据飞轮跑通（投票/纠错入库），工作台 v0 可用，开始服务 10 个种子卖家
- **M3（备案后）**：迁国内节点，支付宝商户开通，工作台订阅收费
