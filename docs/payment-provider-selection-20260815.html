四、Creem 接入清单（待你提供）

Creem 官方 API（docs.creem.io）要点：认证 x-api-key；POST https://api.creem.io/v1/checkouts；webhook 验签 creem-signature = HMAC-SHA256(secret, rawBody)。

  • ① 注册 Creem 账号：creem.io，创建 3 个商品（9.9 / 29.9 / 99）
  • ② 拿 API Key：Dashboard → Settings → API Keys
  • ③ 拿 Product ID：每个商品一个 product id（按 planCode 映射）
  • ④ 配 Webhook：Dashboard → Developers → Webhook，拿 Webhook Secret，回调地址填 https://aifanyi.com/api/credits/webhook/creem
  • ⑤ 给我三个值：CREEM_API_KEY / CREEM_PRODUCT_ID（×3）/ CREEM_WEBHOOK_SECRET

凭据到位后：我填充 creem.ts 真实 createCheckout + verifyWebhook → 配 PAYMENT_PROVIDER=creem 重启 → 小额实测（1 美元单）→ 放开。
